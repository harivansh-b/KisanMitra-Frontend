# KisanMitra Frontend

A responsive UI prototype for KisanMitra's seven agricultural trade actors. The project is frontend-only and uses local JSON fixtures from `mockdata/`.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Use the **Viewing as** control to switch between Farmer, FPO, Buyer, Storage Manager, Transport Manager, Quality Assessor and Admin workspaces.

## Validation

```bash
npm run lint
npm run build
```

Product and UI decisions are indexed in [`docs/README.md`](docs/README.md).
