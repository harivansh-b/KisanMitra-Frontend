# Project Guidance

- This repository is for frontend UI/UX only. Store any data needed by the UI as JSON files in `mockdata/`.
- Design every actor experience responsively for both desktop and mobile.
- Drive all styling through centralized semantic theme tokens and reusable component variants; do not hardcode visual values in individual screens or components.
- KisanMitra is a market-intelligence and transaction-enablement interface for farmers, FPOs, and verified buyers, focused on transparent price discovery and reliable farm-to-buyer linkages.
- The product domain includes mandi and buyer prices, demand and quality requirements, arrivals, price trends and sale-window guidance, produce and offers, logistics and storage, payment tracking, and grievances.
